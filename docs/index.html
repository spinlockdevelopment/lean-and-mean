lean-and-mean

Short answers, minimal code, and an AGENTS.md that remembers every correction. Shorter sessions, less code nobody asked for, no repeat mistakes.

Install

The problem

Coding assistants say and build too much: padded answers, plus helpers, options and abstractions nobody asked for, all of which must be read, reviewed and maintained. And they forget: every session starts blank, so yesterday's corrected mistake can happen again today.

lean-and-mean fixes both by writing a short set of instructions into root AGENTS.md. Codex loads it directly; Claude Code loads it through a one-line CLAUDE.md containing @AGENTS.md. The instructions are then present every session with no plugin code running.

What it does

Minimal code

A YAGNI ladder picks the smallest change that works. New code comes last.

Rules that stick

Every correction becomes one dated line under ## Rules. The file loads every session, so the mistake doesn't repeat.

Clean handoffs

/endsession records Rules, the next task and the Todo list, commits and pushes, then stops. The next session starts small and on the right task.

Short answers

The answer comes first. Full sentences for explanations, short lines for status. No filler, no hedging. Short sentences in active voice, about 80% of the ASD-STE100 controlled language. A diagram or an HTML page when that explains it better.

The YAGNI ladder

Before writing code, the assistant stops at the first step that works:

  1. Only maybe needed later? Skip it and say so.
  2. Already in the project? Reuse it.
  3. In the standard library? Use it.
  4. Native to the platform (browser, OS, framework)? Use it.
  5. An installed dependency does it? Use it.
  6. Fits in one line? One line.
  7. Otherwise, the smallest new code that works.

Minimal never means careless. It never cuts input validation at trust boundaries, error handling that prevents data loss, security, accessibility, or anything you asked for. Also:

  • Root cause. Bugs are fixed at the shared place they come from, not in every caller.
  • Labeled shortcuts. A deliberate shortcut gets a comment such as // lean: up to 1,000 rows, stream if larger; /lean-and-mean debt lists them all.
  • One runnable check for logic with branches, loops, parsing, money or security.
  • A skipped note. After code, at most three lines on what was left out and when to add it.

An AGENTS.md that maintains itself

  • Rules. Each correction becomes one dated line, capped at 15 so the list stays readable.
  • Next and Todo. ## Next names the very next task; ## Todo is a short prioritized backlog. History stays in git log.
  • Fixed layout. Operating Mode, Project & Stack, Commands, Architecture & Layout, Conventions, Done, Rules, Next, Todo, Notes & Pointers, always in that order.
  • 250-line cap. The file is resent on every request, so overflow moves to linked agents-<category>.md files.

Commands

CommandEffect
/lean-and-meanCreate or clean up AGENTS.md: refresh the instructions, reorder sections, verify commands and paths, prune stale lines. Safe to rerun; usually runs on its own.
/lean-and-mean debtList every // lean: shortcut and its upgrade path. Changes nothing.
/endsessionSave Rules, Next and Todo, commit and push, then stop. When the work meets the project's ## Done, it also merges, prunes merged branches and deploys as that section says; when it doesn't, Next says what remains. Ending at natural break points keeps sessions cheap and focused. Details.

Claude Code plugin installs spell them /lean-and-mean:lean-and-mean and /lean-and-mean:endsession; Codex uses $lean-and-mean and $endsession.

What happens automatically

A session-start hook stays silent unless:

  • The instructions aren't in AGENTS.md. It loads them for this session and suggests /lean-and-mean to make them permanent.
  • A cleanup is due: the plugin was updated, the file passed 250 lines, the last /endsession flagged a review, or CLAUDE.md holds more than the stub (the cleanup moves it into AGENTS.md). The assistant runs the cleanup before your first task.
  • No advisor is set (Claude Code only).

The session band mod

Claude Code only. A small plugin module that draws a row above the prompt:

tasks 2/3   [ hide tasks ]  [ end session ]
  ✓ Fix the login redirect
  ✓ Add a test for it
  ☐ Update the changelog
  • Task checklist. Haiku keeps it after each turn. The End session button runs /lean-and-mean:endsession.
  • Auto end. With 5 minutes left on the 1-hour prompt cache, it runs /endsession itself, so the handoff is written before the cache goes cold. Off in /config → Session band.

Extras

Each extra is covered in full in the guide.

  • dashboard-builder (Claude Code). A subagent for any task over about five steps or 30 minutes; its description tells Claude to use it, and you can ask for it by name. It builds .dashboard/index.html, a self-refreshing page with tasks, open questions and deliverables. Claude updates it after every step. How the dashboard works.
  • explainer (Claude Code). A subagent that writes .pages/<slug>.html, a self-contained page with inline SVG diagrams, when an answer runs past a screen, compares options, or will be revisited. How the explainer works.
  • Status line (Claude Code). extras/statusline.sh adds context use and a prompt-cache countdown to your status line; you copy it in yourself. Setup.
  • Advisor. Claude Code can consult a stronger model before a plan, on a recurring error, and before declaring done. Enable once with /advisor fable or /advisor opus. Run the main session at high effort and routine subagent work on Sonnet at medium. Advisor and effort settings.
  • typesafe-ai. TypeSafe AI's skill for building features on their Jev model, which turns text and app state into typed yes/no and pick-one answers. Routed through OpenRouter with OPENROUTER_JEV_API_KEY. Disabled for now: the assistant won't load it on its own. What Jev is for.

Why it pays off

4×cost per request over 400K context versus under 100K ($0.33 vs $0.08): restart at task boundaries
$1.21 vs $0.27median cost to resume after an hour away versus starting fresh; the worst resume measured, at 455K, was $8.79
$0.27median /endsession: a deliberate handoff instead of lossy compaction

Measured from 63 sessions and 5,197 requests (2026-09-03 to 2026-10-03) at API list prices, mostly on Opus 5, whose cache reads cost $0.50; on Opus 5.5 at $0.20 the absolute figures are lower. Every tool call resends the whole context, so cost scales with requests × context size. See why sessions should be short for the full model.

Install

Claude Code

claude plugin marketplace add spinlockdevelopment/lean-and-mean
claude plugin install lean-and-mean@lean-and-mean

Restart Claude Code and run /lean-and-mean:lean-and-mean once in each project to write AGENTS.md and the CLAUDE.md stub. Until then the hook loads the instructions each session and reminds you.

Codex

codex plugin marketplace add spinlockdevelopment/lean-and-mean
codex plugin add lean-and-mean@lean-and-mean

Start a new session at the project root, trust the SessionStart hook when prompted, and run $lean-and-mean once.

No plugin support, or want bare command names? See manual install.

Turning it off

Disable the plugin and delete the ## Operating Mode section from AGENTS.md. The instructions live in the file, so disabling alone isn't enough.

Raw instructions

The plugin is plain text the model follows:

  • operating-mode.md — the block written into AGENTS.md
  • lean-and-mean/SKILL.md — setup, cleanup and file structure
  • endsession/SKILL.md — the session handoff

Also bundles typesafe-ai, TypeSafe AI's skill for the Jev model, routed through OpenRouter. Copyright and credit: TypeSafe AI (MIT). lean-and-mean is MIT licensed.
