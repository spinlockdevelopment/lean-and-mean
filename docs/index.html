lean-and-mean

Short answers, minimal code, and an AGENTS.md that remembers every correction. Shorter sessions, less code nobody asked for, no repeat mistakes.

Install

What it does

Minimal code

Before writing code: skip speculative work, then reuse the repo, the standard library, the platform, an installed dependency, or one line. New code comes last. Validation, data-loss handling, security and accessibility are never cut.

Rules that stick

Every correction becomes one dated line under ## Rules in AGENTS.md. The file loads every session, so the mistake doesn't repeat.

Clean handoffs

/endsession offers to commit, records Rules, the next task and the Todo list, then stops. The next session starts small and on the right task.

Short answers

The answer comes first. Full sentences for explanations, short lines for status. No filler, no hedging.

How it works

The rules live in root AGENTS.md, which Codex loads directly and Claude Code loads through a one-line CLAUDE.md containing @AGENTS.md. The file has fixed sections in a fixed order (Commands, Layout, Conventions, Rules, Next, Todo) and stays under 250 lines.

CommandEffect
/lean-and-meanCreate or clean up AGENTS.md: refresh the rules, verify commands and paths, prune stale lines. Runs on its own when due.
/lean-and-mean debtList every // lean: shortcut marker and its upgrade path.
/endsessionCommit, save Rules, Next and Todo, then stop.

A session-start hook stays silent unless the rules are missing, a cleanup is due (plugin updated, file over 250 lines, review flagged, or CLAUDE.md is more than the stub), or no /advisor is set. Codex uses $lean-and-mean and $endsession; Claude Code plugin installs spell them /lean-and-mean:lean-and-mean and /lean-and-mean:endsession.

Why it pays off

−20 to −40%per long session by restarting at task boundaries (Fable 5.1 to Opus 5)
~$8 vs ~$0.60to resume a 400K Fable session after an hour away, versus starting fresh
~$1for /endsession at 400K: a deliberate handoff instead of lossy compaction

Modeled from API list prices (September 2026), not measured. Every tool call resends the whole context, so cost scales with requests × context size. Details in the README.

Install

Claude Code

claude plugin marketplace add spinlockdevelopment/lean-and-mean
claude plugin install lean-and-mean@lean-and-mean

Restart Claude Code. The first session in each project writes AGENTS.md and the CLAUDE.md stub.

Codex

codex plugin marketplace add spinlockdevelopment/lean-and-mean
codex plugin add lean-and-mean@lean-and-mean

Start a new session at the project root, trust the SessionStart hook when prompted, and run $lean-and-mean once.

Raw instructions

The plugin is plain text the model follows:

  • operating-mode.md — the block written into AGENTS.md
  • lean-and-mean/SKILL.md — setup, cleanup and file structure
  • endsession/SKILL.md — the session handoff
