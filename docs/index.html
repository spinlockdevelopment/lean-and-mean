Claude Code plugin

lean-and-mean

Concise prose, YAGNI code, and a CLAUDE.md that maintains itself. Shorter sessions, less code nobody asked for, and no repeat mistakes.

Install View on GitHub

What it does

Code: a YAGNI ladder

Skip speculative work. Reuse what's in the repo, then stdlib, then the platform, then an installed dependency, then one line, and only then new code. Never cuts validation, data-loss handling, security or accessibility.

Memory: binding Rules

Every correction and failed approach becomes one dated line in CLAUDE.md that Claude must follow next time, so it doesn't happen twice.

Sessions: a clean handoff

/endsession offers to commit, records Rules, the next action and the Todo list, then stops. The next session starts small and on the right task.

Prose: readable

Answers lead with the result. Full sentences for explanations, short lines for status. No filler.

Why it pays off

Every request in a Claude Code session resends the whole conversation, and every tool call is a request. Caching makes each resend cheap, but it's billed every time, so cost grows with the number of requests times the size of the context. Long sessions get expensive per turn.

~20–40%less per long session by restarting at task boundaries (Fable 5.1 to Opus 5)
~$8to re-cache a 400K session on Fable after an hour away, versus ~$0.60 for a fresh start
~$1for /endsession at 400K context, because it does only the cheap work

Rehydration: the cost of walking away

Claude Code caches for an hour. Come back later and the next turn writes the whole context back into cache at twice the input price before doing any work.

Context when you come backFable 5.1Opus 5
400K~$8~$4
Fresh session (~30K)~$0.60~$0.30

Compaction doesn't save you here. It fires late, after you've paid the large-context cost on every turn, and its summary is lossy. /endsession writes a deliberate handoff instead.

Code nobody asked for is paid for three times

  • As output, the most expensive token: a 150-line speculative helper with tests is about 3K tokens, roughly $0.15 on Fable.
  • As context on every later request: about another $0.15 over 200 requests, and again on every edit.
  • In your time, which is the real cost: every extra line is reviewed, tested and maintained.

The YAGNI ladder stops it at the source, "one runnable check" keeps tests proportionate, and // lean: markers record every shortcut's ceiling and upgrade path so skipped work stays visible.

Figures are modeled from Anthropic's API list prices (September 2026: Fable 5.1 at $50 per million output tokens and $0.25 per million cache reads; Opus 5 at $25 and $0.50; cache writes at 2× input with the 1-hour TTL) and round-number session shapes, not measured. Subscription plans meter the same tokens against usage limits, so the proportions carry over. Concise prose itself saves only a few percent; it's there for readability.

A structured CLAUDE.md

CLAUDE.md is loaded on every request, so its size and shape matter.

  • Fixed sections, fixed order. Claude always knows where the commands, layout, conventions and Rules are, and where to write new ones.
  • A 250-line cap. Cheap to carry on every turn. Anything bigger is split into claude-<category>.md files with a pointer.
  • Verified commands and paths. Stale instructions are pruned, so Claude doesn't burn turns on them.
  • ## Next makes restarts cheap. A new session reads one line and starts on the right task.
  • git log is the history. No session log to maintain; /endsession offers to commit first.

Hygiene that runs itself

After setup you rarely run anything by hand. One small shell hook runs at session start and stays silent unless something needs attention:

  1. The Operating Mode block in CLAUDE.md is out of date because the plugin was updated.
  2. CLAUDE.md has grown past 250 lines.
  3. The last /endsession flagged that the project's layout, commands, stack or conventions changed.

Any of these, and Claude runs the full review before your first task, on a fresh and cheap context: re-check commands and paths, restructure, prune finished work, split if too long.

Install

In Claude Code:

/plugin marketplace add spinlockdevelopment/lean-and-mean
/plugin install lean-and-mean@lean-and-mean

Or from your shell:

claude plugin marketplace add spinlockdevelopment/lean-and-mean
claude plugin install lean-and-mean@lean-and-mean

Restart Claude Code, then run /lean-and-mean:lean-and-mean once in each project to write the block into its CLAUDE.md. End sessions with /lean-and-mean:endsession.

No dependencies: a short POSIX shell hook and Markdown skills. MIT licensed.
