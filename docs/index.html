Claude Code plugin

lean-and-mean

Concise prose, YAGNI code, and a CLAUDE.md that maintains itself. Shorter sessions, less code nobody asked for, and no repeat mistakes.

Install View on GitHub

What it does

Code: a YAGNI ladder

Skip speculative work. Reuse what's in the repo, then stdlib, then the platform, then an installed dependency, then one line, and only then new code. Never cuts validation, data-loss handling, security or accessibility.

Memory: binding Rules

Every correction and failed approach becomes one dated line in CLAUDE.md that Claude must follow next time, so it doesn't happen twice.

Sessions: a clean handoff

/endsession offers to commit, records Rules, the next action and the Todo list, then stops. The next session starts small and on the right task.

Prose: readable

Answers lead with the result. Full sentences for explanations, short lines for status. No filler.

Why it pays off

Every tool call resends the whole context as cache reads, so cost scales with requests × context size. Long sessions get expensive per turn.

−20 to −40%per long session by restarting at task boundaries (Fable 5.1 to Opus 5)
~$8 vs ~$0.60to resume a 400K Fable session after an hour away, versus starting fresh
~$1for /endsession at 400K: a deliberate handoff instead of lossy compaction
30K → 500K over ~300 requestsOne sessionThree, restarted
Fable 5.1~$60~$49
Opus 5~$60~$37

Unrequested code is paid three times: as output (~3K tokens for a speculative helper with tests, ~$0.15 on Fable), as context on every later turn (~$0.15 more), and in review and maintenance, the real cost. The YAGNI ladder stops it at the source.

Modeled from API list prices (September 2026: output $50 / $25 per million on Fable 5.1 / Opus 5, cache reads $0.25 / $0.50, 1-hour cache writes at 2× input), not measured. Subscription plans meter the same tokens. Concise prose saves only a few percent; it's for readability.

A CLAUDE.md that maintains itself

  • Fixed sections, fixed order. Commands, layout, conventions and Rules are always where Claude expects them.
  • Rules. A mistake costs one session, not every session.
  • ## Next. A fresh session starts on the right task from one line; git log is the history.
  • 250-line cap. Cheap to carry on every request; overflow splits into claude-<category>.md.
  • Automatic review. At session start, when the block is out of date, the file is over the cap, or /endsession flagged changed layout or commands, Claude re-verifies commands and paths and prunes stale entries. Otherwise the hook stays silent.

Install

In Claude Code:

/plugin marketplace add spinlockdevelopment/lean-and-mean
/plugin install lean-and-mean@lean-and-mean

Or from your shell:

claude plugin marketplace add spinlockdevelopment/lean-and-mean
claude plugin install lean-and-mean@lean-and-mean

Restart Claude Code, then run /lean-and-mean:lean-and-mean once in each project to write the block into its CLAUDE.md. End sessions with /lean-and-mean:endsession.

No dependencies: a short POSIX shell hook and Markdown skills. MIT licensed.
